# Zomato-Sales-Restaurant-Analytics-Dashboard
Designed and developed a dynamic Power BI dashboard to analyze Zomato restaurant operations, customer behavior, sales performance, and business KPIs. This project focuses on transforming raw restaurant and order data into actionable insights through interactive visualizations and business intelligence reporting.

The dashboard enables stakeholders to monitor restaurant performance, customer trends, revenue insights, and operational efficiency in a visually intuitive manner.
